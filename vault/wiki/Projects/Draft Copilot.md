## Summary
This source describes a small local web application designed to assist users during a live 12-team, full-PPR snake fantasy football draft on Sleeper. The main goal of the tool is to provide real-time pick tracking and recommendations based on expert consensus rankings.

## Key points
- A small local web app ran alongside a live Sleeper fantasy football draft. ([[raw/Draft Copilot|Draft Copilot.md]])
- The app tracked every pick in real time and recommended who to take next. ([[raw/Draft Copilot|Draft Copilot.md]])
- The goal was a tool to use during a 12-team, full-PPR snake draft on Sleeper. ([[raw/Draft Copilot#Objective|§ Objective]])
- Recommendations should come from expert consensus rankings, not Sleeper's ADP. ([[raw/Draft Copilot#Objective|§ Objective]])
- The default rankings blend FantasyPros consensus and ESPN Field Yates PPR rankings. ([[raw/Draft Copilot#Rankings dataset|§ Rankings dataset]])
- A player on both lists gets FantasyPros_rank × 0.6 + ESPN_rank × 0.4, and the list is re-sorted by that blended score. ([[raw/Draft Copilot#Rankings dataset|§ Rankings dataset]])
- The app fetches picks every 3 seconds. ([[raw/Draft Copilot#Features|§ Features]])
- Sleeper's CDN caches the picks endpoint for up to 30 seconds. ([[raw/Draft Copilot#Features|§ Features]])
- My Team and Needs tracker automatically detects your own picks and slots them into starting slots. ([[raw/Draft Copilot#Features|§ Features]])
- Check for an API before building scraping or screenshot reading. ([[raw/Draft Copilot#Lessons|§ Lessons]])

## Details

### Approach
- A screenshot app was rejected because reading text from images is unreliable. ([[raw/Draft Copilot#Choosing the architecture|§ Choosing the architecture]])
- The live companion was the easier option because Sleeper has a public, no-login JSON API for drafts. ([[raw/Draft Copilot#Choosing the architecture|§ Choosing the architecture]])

### Features
- Best Available shows consensus rankings with anyone already drafted by any team removed. ([[raw/Draft Copilot#Features|§ Features]])

### The Value Model
- Raw consensus rank answers who is the better player, but not who is the better pick right now. ([[raw/Draft Copilot#The Value Model|§ The Value Model]])
- The value model adds position scarcity as a secondary nudge to the raw consensus rank. ([[raw/Draft Copilot#The Value Model|§ The Value Model]])
- The first version used `replacement_rank − position_rank` alone. ([[raw/Draft Copilot#How the model evolved|§ How the model evolved]])
- This first version answered the 2.10 question by favoring the RB11 over the TE1, but it let scarcity override real differences in talent. ([[raw/Draft Copilot#How the model evolved|§ How the model evolved]])

### Bugs Found and Fixed
- The 'My Team' empty in mock drafts bug was caused by Sleeper leaving `roster_id` null on mock-draft picks. ([[raw/Draft Copilot#Bugs Found and Fixed|§ Bugs Found and Fixed]])
- The fix for the 'My Team' empty in mock drafts bug was to identify picks by `draft_slot`, which is set in both mock and real drafts. ([[raw/Draft Copilot#Bugs Found and Fixed|§ Bugs Found and Fixed]])

### Lessons
- Test on a mock draft before relying on the app live. ([[raw/Draft Copilot#Lessons|§ Lessons]])
